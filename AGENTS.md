# AGENTS.md

accounting-sync is an OCaml (OxCaml) library that exports double-entry ledger journals
to external accounting systems. Build from the workspace root with
`DUNE_BUILD_DIR=_build-accounting-sync opam exec --switch 5.2.0+ox -- dune build --root .. @accounting-sync/all`.
See `../oxcaml-claude-skills/AGENTS.md` for the workspace-wide guide.
